Самым сложным при разработке бэкенда было настроить работу пользователей и их сохранение. Нужно было сделать так, чтобы регистрации, подписки и другие действия пользователей правильно обрабатывались и не сбрасывались после обновления страницы. Также возникали ошибки при связи бэкенда с фронтендом, приходилось проверять работу отдельных функций.
